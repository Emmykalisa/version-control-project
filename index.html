HOW IT WORKS

Get Started in 4 Simple Steps

Follow this workflow to manage your first project.

01

Create Your Project

Create a new project or open an existing project on your computer.

mkdir my-project
02

Initialize Git

Create a local repository and start tracking changes to your files.

git init
03

Commit Your Changes

Stage your files and save a version with a meaningful commit message.

git add . git commit -m "First version"
04

Push to GitHub

Connect your local repository to GitHub and upload your saved versions.

git push
